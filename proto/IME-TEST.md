# IME 驗證清單

目的：在選定 UI 框架前，確認繁體中文輸入法（注音、倉頡等）在各候選框架上的行為。

## 執行方式

```powershell
cargo run --release -p ime-egui
cargo run --release -p ime-iced
cargo run --release -p ime-slint
```

## 測試項目

每個原型都依序測試，並記錄結果（○ 正常 / △ 有瑕疵 / ✕ 失敗）。

| # | 項目 | 操作 | 預期結果 |
|---|---|---|---|
| 1 | 組字顯示 | 輸入注音 `ㄋㄧˇ` 先不選字 | 文字框內看到帶底線的組字中文字 |
| 2 | 候選窗位置 | 在文字框不同位置（左上、右下、換行後）輸入 | 候選窗緊貼游標，不跑到螢幕角落 |
| 3 | 確認輸入 | 按 Space 選字、Enter 確認 | 文字正確上屏，Enter 不會多換一行 |
| 4 | 組字中取消 | 組字中按 Esc | 組字內容消失，不留殘字 |
| 5 | 組字中移動游標 | 組字中按方向鍵、Backspace | 行為與記事本一致 |
| 6 | 連續輸入 | 快速輸入一整句（20 字以上） | 不掉字、不卡頓、不重複 |
| 7 | 游標位置 | 在句子中間插入中文 | 插入位置正確，後方文字順移 |
| 8 | 選取後輸入 | 選取一段文字再輸入中文 | 選取內容被取代 |
| 9 | 中英混打 | `Hello 你好 world` | 空格、半形與全形字元間距正常 |
| 10 | 倉頡、拼音 | 切換不同輸入法重做 1～3 | 與注音一致 |
| 11 | 標點與全形 | 輸入 `，。「」？！` | 正確上屏 |
| 12 | 文字渲染 | 觀察字型 | 無缺字方塊、字形不破碎 |
| 13 | 高 DPI | 螢幕縮放 125%、150% | 候選窗位置不偏移 |
| 14 | 視窗移動 | 組字中拖曳視窗 | 候選窗跟著移動 |
