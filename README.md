# FEditor

以 EmEditor 為觀摩對象、支援 scripting 巨集的跨平台文字編輯器，以 Rust 實作。

- **大檔案也順暢**：幾百 MB、上百萬行的檔案可以直接開啟編輯。
- **多分頁、可任意分割的窗格**：分頁可以拖來拖去，內建**預覽**（Markdown、CSV、JSON…）與**終端機**，都和分頁一樣能放進任何窗格。
- **中文友善**：繁體中文輸入法、中日韓全形字對齊、自動偵測 Big5／GBK／Shift_JIS 等編碼。
- **可擴充**：JavaScript 巨集（可錄製）、預覽外掛、自訂配色與語法上色。
- **介面**：淺色／深色各自選配色（內建 18 套，含 Dracula、Nord、Catppuccin 等），介面語言可選中文或 English。

## 下載與安裝

到 [Releases](https://github.com/codemee/feditor/releases) 下載對應平台的壓縮檔：

- **Windows**：下載 `feditor-windows-x64.exe`，直接執行（單一檔案，不需要安裝，也不用解壓縮）。
- **macOS**（Apple Silicon）：下載 `feditor-macos.dmg`，開啟後把 `FEditor.app` 拖到旁邊的「應用程式」捷徑。沒有公證，第一次開啟要在 Finder 對它按右鍵 →「打開」，或執行 `xattr -dr com.apple.quarantine FEditor.app`。
- **Linux**：解壓縮後執行 `./feditor`。

也可以用命令列開啟檔案：`feditor 檔案路徑`，或把檔案從檔案總管拖進視窗（可一次拖多個，各開一個分頁）。拖進**資料夾**時，會以該資料夾為起點顯示「開啟檔案」交談窗。每個版本改了什麼，請看[更新紀錄](CHANGELOG.md)。

## 基本操作

操作以**工具列按鈕**為主，不使用功能表。按鈕只顯示圖示，文字說明（含快捷鍵）放在 tooltip。

| 按鈕 | 快捷鍵 | 說明 |
|---|---|---|
| 新增／開啟／儲存／另存新檔 | Ctrl+N／O／S／Shift+S | 基本檔案操作；關閉或切換文件前，有未儲存的修改會先詢問 |
| 尋找與取代 | Ctrl+F（取代 Ctrl+H）、F3／Shift+F3 | 開啟尋找列（見下） |
| 在檔案中尋找 | Ctrl+Shift+F | 在資料夾底下的所有文字檔裡搜尋 |
| 終端機（`>_`） | Ctrl+Shift+`（新增）、Ctrl+`（切換焦點） | 新增終端機分頁（見下） |
| 預覽（眼睛） | Ctrl+Shift+P | 開關預覽窗格（見下） |
| 巨集面板／重跑 | F5（重跑） | 執行、設快捷鍵、編輯、刪除巨集；失敗時自動還原所有修改 |
| 錄製巨集 | | 開始／停止錄製按鍵與輸入，存成巨集 |
| 設定（⋯，最右邊） | | 介面語言、外觀、配色、字型、字級、顯示選項 |
| 字級 | Ctrl ＋／－、Ctrl＋滾輪、Ctrl＋0 | 調整字級；點在預覽窗格上時調的是預覽的字級 |
| 分頁 | Ctrl+W 關閉、Ctrl+Tab／Ctrl+Shift+Tab 切換 | 見下 |

狀態列左側是檔案路徑，右側是這個檔案的格式設定：**語言**（語法上色）、**編碼**（含 BOM）、**換行**、**重新載入**（自動偵測編碼錯誤時，改以指定編碼重新讀取），以及游標位置「行 X，欄 Y」（欄號裡全形字算 1 欄或 2 欄，可在設定面板選）。狀態列上方是**輸出面板**，放開檔訊息、警告、錯誤與巨集的輸出，預設收合成一條，出現錯誤時會暫時彈開。

## 分頁與窗格

- 開啟的檔案各是一個分頁，游標、選取與復原歷史各自獨立。已經開著的檔案再開一次會切過去，不會重複。未儲存的分頁名稱後有「●」。
- **雙按分頁重新命名檔案**：預設只選取主檔名，按 Enter 就真的把磁碟上的檔案改名。檔名不合法、已有同名檔案、或別的分頁已經開著那個檔案時，會在對話框裡說明，不會覆蓋。還沒存成檔案的分頁，雙按會開「另存新檔」。
- **分割窗格**：把分頁拖到編輯區的左、右、下側，就往那個方向切出新窗格（拖曳時會預覽範圍）；放到另一個窗格中間，就加入那個窗格的分頁列。窗格可以一直切下去、任意組合，間隙可以拖曳調整大小，窗格不會小於 240×140 點。拖曳途中按 Esc 取消。
- 有強調色框線的是**有焦點的窗格**（點一下就會換），尋找、儲存、巨集、狀態列都作用在它目前的分頁。窗格裡最後一個分頁關掉時窗格一起關；也可以按分頁列右端的按鈕關閉窗格，裡面的分頁（包含未儲存的修改）會移到相鄰的窗格。
- 分頁放不下時不顯示捲軸：兩側有 `<` `>` 箭頭可以捲動（滑鼠滾輪也行），右邊的 `v`「選擇分頁」下拉清單可以直接選。
- **記住上次的狀態**：關閉再重開，所有窗格（各自的分頁、作用中的分頁、游標位置、分隔線比例、預覽窗格與終端機分頁）都會還原；已經不存在的檔案會略過。終端機會開成新的 shell。
- **外部修改偵測**：檔案被別的程式改了，沒有未儲存的修改就自動重新載入（保留游標位置）；有的話會詢問，背景分頁則在標籤標上「（磁碟上已變更）」，切過去時再問。檔案被刪除或移走時標籤標上「（已刪除）」，內容仍保留，存檔會重新建立檔案。

## 預覽

按工具列的**眼睛**，會在目前窗格的右邊開一個預覽窗格，顯示**目前有焦點的文件**的預覽，改文字會即時更新。整個程式只有一個預覽窗格，所有文件共用。

| 檔案 | 預覽的樣子 |
|---|---|
| Markdown（`.md`） | 標題、粗體／斜體、連結、清單、引用、程式碼區塊、表格、本機圖片；HTML 只認得 `<kbd>`、`<picture>`／`<img>`（依深淺色主題挑圖）與 `<br>` |
| CSV、TSV | 表格，欄寬可以拖曳 |
| JSON、TOML、YAML | 可摺疊的樹，格式錯誤時顯示出錯的行與欄 |
| SVG | 直接顯示圖形，邊改邊更新 |

預覽裡的連結：網址、信箱等交給預設的瀏覽器；指向**本機檔案**的連結（相對路徑以文件所在資料夾為準）會在編輯器的新分頁開啟，已經開著的就切過去。預覽窗格可以拖到版面的任何位置，點一下它就能用 Ctrl ＋／－ 調整預覽自己的字級。想預覽別的檔案類型，可以自己寫 JavaScript **預覽外掛**（見[預覽外掛](docs/preview-plugins.md)）。

## 終端機

工具列的 `>_`（Ctrl+Shift+`）新增一個終端機，執行系統預設的 shell（Unix 用 `$SHELL`；Windows 優先 PowerShell 7，其次 Windows PowerShell，最後 cmd）。

- **終端機是一種分頁**：標籤是「終端機 1」「終端機 2」…，前面有它執行的 shell 的圖示（見下），**雙按標籤可以自己取名**（留空改回預設）。標籤可以像文字分頁一樣拖：拖到別的窗格中間就加入那個窗格的分頁列，拖到窗格側邊就切成新窗格。切到別的分頁時，shell 照常在背景執行。
- **預設終端機與 shell 清單**：工具列的終端機鈕旁有個下拉箭頭，列出這台機器上找得到的 shell（Windows：PowerShell 7、Windows PowerShell、cmd、Git Bash、WSL、Nushell；macOS／Linux：`$SHELL` 與 `/etc/shells` 裡存在的），每一項前面有那個 shell 的圖示（Windows 上取自執行檔本身，和檔案總管看到的一樣；其他系統用通用的終端機圖示），方便分辨。選一個就用它新增終端機，只影響那一個。按鈕本身用**預設終端機**（設定面板「終端機」群組，從同一份清單選，也可以自己寫指令；沒設定就是系統預設）。已經開著的終端機不受之後改的設定影響。
- Ctrl+` 讓焦點依序在各個終端機之間循環，繞完一圈回到原來的分頁。shell 結束（輸入 `exit`）或按標籤的 ×，那個分頁就關掉。
- 支援顏色、全螢幕程式、輸入法、複製貼上（有選取文字時 Ctrl+C 是複製，否則中斷程式）、滑鼠拖曳選取、滾輪捲動。顏色跟著目前的配色方案走，文字和底色對比太低時會自動調整到看得清楚。
- 程式要求滑鼠回報（vim、htop 這類）時，滑鼠事件會送給程式；按住 Shift 仍然可以選取文字。
- **網址**：按住 Ctrl 把滑鼠移到網址（`http`、`https`、`ftp`、`file`）上，整段網址會加底線、游標變成手指，點一下就用預設瀏覽器開啟；跨越折行的網址也能點。
- **搜尋**：終端機有焦點時按 Ctrl+F（和編輯區一樣），右上角會出現搜尋列。vim、less 這類全螢幕程式執行時，Ctrl+F 仍然交給程式。輸入就即時找，不分大小寫，連往上捲出去的歷史也找；符合的字會標色，Enter 找較早的一筆、Shift+Enter 找較新的一筆，Esc 關閉。

## 編輯

- **自訂繪製的編輯區**，只繪製看得到的行，所以檔案再大也順暢。中文與全形字一律佔兩欄，上下行的英數字都會對齊；游標以「字」為單位移動（組合字元、emoji 算一個）。
- **常用操作**：方向鍵、Home／End、Ctrl＋方向鍵（以詞為單位）、Shift 選取、Ctrl+Z／Y 復原重做、Ctrl+X／C／V。Enter 沿用上一行縮排；滑鼠雙擊選詞、三擊選行。
- **行操作**：Alt＋↑／↓ 移動行、Shift＋Alt＋↑／↓ 複製行、Ctrl+Shift+K 刪除行、Ctrl+/ 註解切換、Ctrl+] ／ Ctrl+[ 縮排／反縮排。
- **多重游標與矩形選取**：Ctrl＋點擊加上游標、Ctrl+D 逐次選取相同的文字、Alt＋拖曳矩形選取、Esc 回到單一游標。
- **自動換行**、**語法上色**（Rust、C/C++、Java/C#、JavaScript/TypeScript、Python、Go、Shell、SQL、CSS、Lua、JSON、TOML/INI/YAML、HTML/XML、Markdown 等，可在狀態列手動選語言，也能自訂語言）、**行號**、**顯示空白字元**，都可以在設定面板開關。
- **復原**以「一段操作」為單位：連續打字、連續刪除各算一步；單次取代、全部取代、整支巨集各是一步。
- **輸入法**：組字中的文字畫在游標處並加底線，不會污染復原歷史，候選窗貼在組字處。
- **檔案格式**：自動偵測編碼（BOM → UTF-8 → Big5 等），記憶原檔的換行（CRLF／LF／CR）並在存檔時還原；存檔先寫暫存檔再改名，目標編碼無法表示的字元會讓存檔**失敗**，不會靜默替換；載入時有無法解碼的位元組，則禁止覆寫原檔。

## 尋找與取代

- 在搜尋框或取代框按 Tab 只會在這兩個框之間切換，其他按鈕預設用滑鼠點。
- 三個選項：規則表達式、區分大小寫（預設不區分）、完整單字；輸入時即時搜尋並顯示「第幾筆／總筆數」，找不到會繞回另一端。滑鼠停在「規則表達式」按鈕上會出現語法速查表。
- 規則表達式使用 Rust `regex` 語法（保證線性時間，不會被寫壞的規則卡死）；取代字串可用 `$1`、`${名稱}` 代入群組，`\n`、`\t` 代表換行與跳位，字面的 `$` 寫 `$$`。
- 取代造成的修改都可以用 Ctrl+Z 復原：單次取代、全部取代各是一步。
- **在檔案中尋找**（Ctrl+Shift+F）：搜尋資料夾底下的所有文字檔（可設檔名過濾，例如 `*.rs;*.toml`），在背景執行、可隨時停止，結果點一下就開啟並選取。會自動偵測編碼，略過二進位檔、超過 20 MiB 的檔案與 `.git`／`target`／`node_modules`；最多列 5000 筆。

## 外觀與設定

工具列最右邊的「⋯」是**設定**面板：

- **介面語言**：三態按鈕（跟隨系統／中文／English），立刻生效。
- **外觀**：三態按鈕（跟隨系統／淺色／深色）。
- **配色**：淺色與深色**各自選一套**。內建深色 11 套（EVA 為預設，另有 Dracula、Monokai、Solarized Dark、One Dark、Nord、Gruvbox Dark、Tokyo Night、Catppuccin 三款）、淺色 7 套（預設淺色、Solarized Light、GitHub Light、One Light、Gruvbox Light、VS Code Light+、Catppuccin Latte）。「編輯目前配色…」可以逐一調整 41 種顏色（含終端機的 16 色）並另存成自訂配色。
- **字型**：只列出等寬字型，預設是作業系統預設的等寬字型。**字級**用面板或快捷鍵調整，兩邊同步。
- **顯示選項**：行號、標示目前這一行、顯示空白字元、語法上色、自動換行。
- **檔案總管／Finder 右鍵選單**：設定面板「介面」頁勾選「加入右鍵選單」（Windows 的標籤是「檔案總管」，macOS 是「Finder」），檔案的右鍵選單會多一個「用 FEditor 開啟」，資料夾（以及資料夾空白處）多一個「用 FEditor 選取檔案開啟…」，後者會顯示「開啟檔案」交談窗，從那個資料夾開始選。Windows 寫在目前使用者的登錄檔（不需要系統管理員權限），Windows 11 的新版右鍵選單要按「顯示其他選項」才看得到；macOS 會在 `~/Library/Services` 產生兩個 Finder 服務項目，在右鍵的「服務」子選單裡（要讓它們也出現在「快速動作」子選單，到「系統設定 → 隱私權與安全性 → 擴充功能 → Finder」勾選）。取消勾選就移除。程式搬了位置或換了介面語言，下次啟動會自動更新。Linux 目前沒有這個功能。也可以直接在命令列給好幾個路徑：`feditor a.txt b.txt 資料夾`。已經有 FEditor 在執行時，用路徑啟動（包括右鍵選單）會把路徑交給它開、並把它的視窗叫到前面，不會另外開新視窗；沒有才自己啟動。不帶路徑啟動（例如從開始功能表）一律開新視窗。FEditor 之間用本機（127.0.0.1）的 49731 埠協調，只接受同一個使用者的 FEditor；那個埠被別的軟體佔用時，就退回每次都開新視窗。

  macOS 上開檔案有兩個入口，作用不同：

  | | 「打開檔案的應用程式」 | 「服務」（上面的開關） |
  |---|---|---|
  | 要不要設定 | 不用，裝好 `FEditor.app` 就有 | 要在設定面板勾選「加入右鍵選單」 |
  | 檔案 | 文字類檔案才會列出 FEditor | 任何檔案都有「用 FEditor 開啟」 |
  | 資料夾 | 沒有 | 有「用 FEditor 選取檔案開啟…」 |
  | 位置 | 右鍵 →「打開檔案的應用程式」 | 右鍵 →「服務」 |
  | 另外 | 可以在「取得資訊」把某類檔案的預設程式設成 FEditor，也可以把檔案拖到 Dock 的圖示 | |

- **自動搜尋執行環境（Python）**：開啟 `.py` 檔時，狀態列（語言的左邊）會顯示找到的 Python，例如「Python 3.12.1 · .venv」。搜尋順序：① 從檔案所在的資料夾往上，每一層找虛擬環境資料夾（`.venv`、`venv`、`env`，要有 `pyvenv.cfg`），走到有 `.git` 的那一層、家目錄或磁碟根目錄就停，不會去用別的專案的環境；② 環境變數 `VIRTUAL_ENV`、`CONDA_PREFIX` 指到的環境；③ `PATH` 上全域的 `python3`／`python`（Windows 另外有 `py` 啟動器，並排除商店的假捷徑）。每個候選都會在背景執行 `--version` 確認真的能用，壞掉的環境會被略過；結果快取 30 秒（什麼都沒找到時 5 秒），視窗從別處回到前景時也會重找，所以在終端機剛建好的虛擬環境很快就會出現；找不到時旁邊有個重新搜尋鈕，找的過程都在背景，不會卡住畫面。狀態列上這一格是下拉清單（前後有分隔線自成一組），點開可以看到所有候選與版本、手動改選別的直譯器（依專案記住，存在設定檔 `runtime.<專案資料夾>`）、回到「自動」或「重新搜尋」。**開終端機時**，如果找到專案的虛擬環境（或手動選了直譯器），shell 的 `PATH` 會自動把它放在最前面並設好 `VIRTUAL_ENV`，所以終端機裡的 `python` 就是這個專案的（不需要執行 `activate`，pwsh、cmd、bash、zsh 都適用）；已經開著的終端機不會變，重開才會套用。搜尋規則是資料（`ui/src/runtime_env.rs` 的 `Rule`），之後要支援別的語言只要再寫一份規則。
- **在終端機執行目前的檔案**：工具列終端機按鈕旁的「執行」鈕（終端機的提示字元，右下角一個播放三角形；旁邊的下拉清單可以設定**命令列參數**，依檔案記住，存在設定檔 `run_args.<檔案路徑>`，原樣接在檔案後面交給終端機的 shell 解析，所以引號、變數的寫法照那個 shell 的規則；在欄位按 Enter 或「執行」就直接執行），用狀態列上選定（或自動找到）的執行環境，在終端機分頁執行目前的檔案，例如 Python 檔會執行 `<直譯器> "檔案"`。有未儲存的修改會先存檔，沒有存成檔案的不能執行；目前只支援有執行環境規則的語言（Python）。第一次執行會開一個終端機，之後重複使用同一個（不會每次多開一個），再次執行前會先送 Ctrl+C 中斷上一次還沒跑完的程式、切到檔案所在的資料夾；那個終端機被關掉就再開一個新的。指令會依終端機的 shell（bash／zsh、PowerShell、cmd）自動加上正確的引號。
- **終端機指令（macOS、Linux）**：設定面板「介面」的「終端機指令」勾選「加入 feditor 指令」，會在 `~/.local/bin` 建立一個很短的 `feditor` 腳本（把程式放到背景啟動，終端機馬上回到提示字元），之後可以在終端機輸入 `feditor 檔案` 開啟；已經開著 FEditor 時，檔案會交給那個視窗。加入時會跳出提醒：`~/.local/bin` 要在 `PATH` 裡，沒有的話把 `export PATH="$HOME/.local/bin:$PATH"` 加到 `~/.zshrc`（bash 用 `~/.bashrc`）再重開終端機。取消勾選就移除；只會動 FEditor 自己建立的腳本，同名的別的檔案不會被覆蓋或刪除。程式搬了位置，下次啟動會自動更新腳本裡的路徑。

  升級後若「打開檔案的應用程式」沒有 FEditor，確認 `FEditor.app` 是新版（舊版會留著舊的登記），必要時執行 `lsregister -f` 重新登記。
- **Tab 欄數與用空白取代 Tab**：設定面板「編輯區」的「Tab 欄數」是預設的欄數（預設 4）；設定面板的「檔案類型」頁用下拉清單選一個檔案類型（語法上色的語言，例如 Python、Go），可以另外設定自己的欄數，沒設定的都用預設的，按右邊的關閉鈕就移除個別設定。「輸入 Tab」勾選「改用空白」後，按 Tab 鍵會補空白到下一個 Tab 位置、多行縮排加一個 Tab 欄寬的空白（所有檔案類型共用）；檔案裡原有的 Tab 字元不會被改，縮排退一層時兩種都退得掉。
- **轉換縮排**：工具列有兩個鈕，「Tab 換成空白」與「縮排空白換成 Tab」，依這份文件的檔案類型的 Tab 欄數換算；有選取只轉選到的行，沒有就轉整份文件。換成空白時每個 Tab 補到下一個 Tab 位置；換成 Tab 時只動行首的縮排（每個 Tab 欄寬一個 Tab，不足的餘數留成空白），行中間對齊用的空白不會動。也可以在巨集用 `editor.run("tabsToSpaces")`、`editor.run("spacesToTabs")`。
- **自動縮排**：按 Enter 時，行尾是左括號 `{ ( [`（Python 還有冒號 `:`）就把下一行多縮排一層；在一對括號之間按 Enter（`{|}`）會展開成三行，游標停在縮排過的中間那行；在只有空白的縮排行行首輸入 `}`、`)`、`]` 會自動少一層。字串與註解裡的括號不算，區塊註解與多行字串裡按 Enter 只沿用縮排。規則依檔案類型決定（Rust、C/C++、Java/C#、JavaScript/TypeScript、Go、CSS、JSON 看括號，Python 看冒號，其他類型只沿用上一行的縮排；自訂語言檔用 `indent = brace|python|none` 指定）。縮排字元跟隨「改用空白」與 Tab 欄數。開關在設定面板「編輯區」的「自動縮排」（預設開），關閉後回到只沿用上一行的縮排。
- **排列格式**：工具列的「排列格式」鈕、編輯區裡的 `Alt+Shift+F`、巨集的 `editor.run("reformat")`。有選取只處理選到的行，沒有就處理整份文件，整件事是一個復原步驟。用括號決定縮排的語言會依括號深度重新排好縮排（深度永遠從檔案開頭累計，所以只選一段也對得上）並去掉行尾空白，區塊註解與多行字串裡的行不動；JSON 會完整重新排版（鍵順序保留；含註解的 JSON 退回括號規則）；Python 與其他沒有深度規則的類型只去行尾空白，並把行首縮排換成目前設定的字元。
  - **括號內斷行**：啟用安全界線時（設定面板「安全界線」勾選），排列格式還會處理圓括號與方括號（函式參數、陣列）：多餘的斷行接回一行，裝不下（超過安全界線）的在括號內斷開；`{ }`（程式區塊）不動，字串與行尾註解不會被切開，括號裡有註解、空行或 `{ }` 的不接合。斷行後下一行怎麼排看語言的「換行風格」：`align` 對齊開括號後的第一個參數（參數盡量排滿一行，閉括號接在最後一個參數後面）；`hang` 開括號後直接換行、每個參數一行並縮排一層、閉括號獨立一行。預設 Python、C/C++、Java/C# 用 `align`，Rust、JavaScript/TypeScript、Go 用 `hang`（並在最後一個參數後面加逗號）。要改的話：在設定面板的「檔案類型」頁選一個檔案類型，再改「換行風格」（選「預設」就回到語言本身的預設）；也可以在設定檔寫 `wrap_style.<語言名稱> = align|hang`（例如 `wrap_style.Rust = align`），自訂語言檔則寫 `wrap = align|hang`、`trailing_comma = true|false`。沒有啟用安全界線時不接合也不斷行。
- **安全界線**：勾選啟用（預設啟用）並設定欄數（預設 80），從那一欄的右緣起，右邊整塊區域會換成淡淡的顏色，一行寫過界線，超出的字就落在換色的區域裡。欄數和畫面一致，全形字算兩欄；沒勾選時欄數也會記著。設定面板裡數字欄位的單位（pt、欄）都寫在欄位外面，欄位裡只輸入數字。
- **終端機**：字級（點在終端機上時 Ctrl ＋／－ 調的就是它，和編輯區、預覽各自獨立）、文字與底色的最低對比度（可以關掉）、預設終端機（從偵測到的 shell 清單選，也可以自己寫指令，可以加參數）。
- 設定存在設定資料夾（Windows `%APPDATA%\feditor\`、macOS `~/Library/Application Support/feditor/`、Linux `~/.config/feditor/`）；設定面板有按鈕可以直接開啟配色、預覽外掛資料夾。

自訂配色檔、自訂語法、設定檔的格式見[自訂與設定檔](docs/customization.md)。

## 巨集

巨集是 JavaScript，放在設定資料夾的 `macros` 資料夾，一個 `.js` 檔一支。

- 工具列的巨集按鈕展開巨集面板：執行、設快捷鍵（Alt/Ctrl 組合）、編輯原始碼、重新命名、刪除。F5 重跑上一支。
- **錄製**：按錄製鈕後，之後的按鍵與輸入會被記下來，再按一次停止並命名，存成可以編輯的 JavaScript（連續打字會併成一句）。滑鼠操作不會錄。
- 一支巨集的執行是**一個復原步驟**；失敗時文字與選取都還原成執行前的樣子。巨集跑在有時間（5 秒）與記憶體（64 MiB）上限的沙盒裡，不能讀寫檔案或連網路。

完整的 API 與檔頭標記見[巨集](docs/macros.md)；範例在 `examples/macros/`。

## 已知問題

- 輸入法只在 Windows 上驗證過，macOS 與 Linux 尚未驗證。
- macOS 的 `FEditor.app` 沒有 Apple 公證，也還沒有完整實測過。Finder 對檔案按右鍵 →「打開檔案的應用程式」會列出 FEditor（宣告成文字類檔案的 Alternate 編輯器，不會搶走預設程式），選了就開檔；把檔案拖到 Dock 的圖示上也行。
- 單行極長（數十萬字元）時該行會變慢；行數超過約 1,000,000 時垂直捲動的位置有精度限制（400 萬行、346 MB 的檔案可以開啟操作，但行距會有肉眼可見的抖動）。
- Windows 的輸入法有焦點時，部分 Ctrl+Alt＋字母的組合會被輸入法吃掉。
- 終端機是實驗功能，目前在 Windows 上測試最完整。
